# DevOps Junior Lab

Laboratorio práctico orientado a proyectos DevOps y SysAdmin nivel junior.

El objetivo de este repositorio es practicar tecnologías reales utilizadas en entornos IT modernos mediante proyectos pequeños, visuales y fáciles de explicar en entrevistas técnicas.

---

# Objetivos

- Aprender Docker y Docker Compose
- Practicar automatización básica
- Entender CI/CD
- Trabajar con monitoring y logs
- Aprender troubleshooting real
- Crear proyectos útiles para portfolio técnico
- Simular workflows DevOps junior

---

# Tecnologías

- Docker
- Docker Compose
- GitHub Actions
- Terraform
- Ansible
- Prometheus
- Grafana
- Loki
- Nginx
- Linux

# Filosofía del proyecto

Este laboratorio NO busca crear una arquitectura enterprise compleja.

La idea es construir:
- proyectos pequeños
- rápidos de desplegar
- fáciles de entender
- útiles para recruiters
- realistas para un entorno junior

---

# Objetivo final

Construir un portfolio técnico:
- profesional
- visual
- práctico
- reutilizable
- orientado a entrevistas DevOps y SysAdmin Junior
