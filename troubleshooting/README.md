# Troubleshooting Basic

Colección de problemas reales encontrados durante el desarrollo del laboratorio DevOps Junior.

Este proyecto no despliega servicios. Su objetivo es documentar errores, causas y soluciones de forma clara y profesional.

## Objetivo

Practicar troubleshooting real en entornos DevOps y SysAdmin junior.

Se documentan problemas relacionados con:

- Docker
- Docker Compose
- Git
- GitHub Actions
- Ansible
- Terraform
- Grafana
- Loki
- Promtail
- Linux

## Estructura

```text
troubleshooting/
├── issues/
├── screenshots/
└── README.md
```

## Casos documentados

| Caso | Tecnología | Problema |
|---|---|---|
| 01 | Docker Compose | `unknown shorthand flag: 'd' in -d` |
| 02 | Git | Carpetas vacías no aparecen en GitHub |
| 03 | Ansible | `sudo: a password is required` |
| 04 | Terraform | Paquete `terraform` no encontrado con apt |
| 05 | Grafana + Loki | Unable to connect with Loki |
| 06 | Promtail + Loki | No logs found |
| 07 | GitHub Actions | Workflow no aparece o no se ejecuta |

## Metodología

Cada caso sigue este formato:

1. Problema
2. Causa
3. Diagnóstico
4. Solución
5. Aprendizaje

## Utilidad real

En entornos IT y DevOps, gran parte del trabajo consiste en analizar errores, leer logs, interpretar mensajes y aplicar soluciones controladas.

Este proyecto demuestra capacidad de diagnóstico y resolución de incidencias técnicas reales.
