# Troubleshooting Basic

Collection of real issues encountered during the development of the DevOps Junior Lab.

This project does not deploy services. Its purpose is to document errors, causes, and solutions in a clear and professional way.

## Objective

Practice real troubleshooting in junior DevOps and SysAdmin environments.

The project documents issues related to:

- Docker
- Docker Compose
- Git
- GitHub Actions
- Ansible
- Terraform
- Grafana
- Loki
- Promtail
- Linux

## Structure

```text
troubleshooting/
├── issues/
├── screenshots/
└── README.md
```

## Documented Cases

| Case | Technology | Problem |
|---|---|---|
| 01 | Docker Compose | `unknown shorthand flag: 'd' in -d` |
| 02 | Git | Empty folders do not appear on GitHub |
| 03 | Ansible | `sudo: a password is required` |
| 04 | Terraform | `terraform` package not found with apt |
| 05 | Grafana + Loki | Unable to connect with Loki |
| 06 | Promtail + Loki | No logs found |
| 07 | GitHub Actions | Workflow does not appear or execute |

## Methodology

Each case follows this structure:

1. Problem
2. Cause
3. Diagnosis
4. Solution
5. Lessons Learned

## Real-World Use Case

In IT and DevOps environments, a large part of the work involves analyzing errors, reading logs, interpreting messages, and applying controlled solutions.

This project demonstrates troubleshooting and real technical incident resolution skills.
